# Arquitectura

La base se encuentra en `layout/theme.liquid`. Los grupos de cabecera y pie enmarcan las plantillas JSON. Las secciones usan Liquid y comparten la hoja de estilos de Travelia. El planificador separa el formulario del motor de reglas. Un backend futuro puede usar el mismo contrato de seis respuestas y conservar sus credenciales en el servidor.
