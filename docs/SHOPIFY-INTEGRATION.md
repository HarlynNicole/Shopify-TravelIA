# Integración con Shopify

Conecta main desde la biblioteca de temas mediante **Agregar tema → Conectar desde GitHub**. Comprueba en la tarjeta del nuevo tema la rama y el último commit. Previsualiza ese tema en la biblioteca. Las ediciones de Shopify pueden crear commits en main. Horizon publicado es independiente. [Guía oficial](https://shopify.dev/docs/storefronts/themes/tools/github)
